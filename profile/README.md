# Ai-Thinker AiPi · 小安派

**安信可科技 · 开源开发板团队**
<sub>Open-source development board team at Ai-Thinker</sub>

[官网](https://www.ai-thinker.com) &nbsp;·&nbsp; [文档](https://docs.ai-thinker.com) &nbsp;·&nbsp; [商城](https://shop.ai-thinker.com) &nbsp;·&nbsp; [社区](https://www.ai-thinker.com/community)

小安派（AiPi）围绕安信可的 Wi-Fi / 蓝牙模组，做开箱即用的开源硬件：开发板、屏幕、摄像头、外壳，以及配套的 SDK、示例固件和烧录工具，全部开源。面向创客、高校教学与工业物联。

<sub>AiPi builds ready-to-use open hardware around Ai-Thinker's Wi-Fi / Bluetooth modules — boards, displays, cameras and enclosures, with the SDKs, sample firmware and flashing tools to match.</sub>

## 产品线

| 系列 | 定位 | 代表型号 |
| --- | --- | --- |
| Eyes | 带屏交互开发板 | AiPi-Eyes-S1 / S2、R1 / R2 |
| Cam | 摄像头方案 | Cam-D200、Cam-U |
| SCP | 中控面板 | SCP-4.3 |
| UNO | UNO 兼容，以太网 / RS485 | AiPi-UNO |
| PalChat | AI 语音对话开发板 | PalChat V1 / V2 / V3 |
| 扩展 | 屏幕驱动、墨水屏、LoRaWAN、KVM | DSL、ESL-2.13、LRW-TH1、KVM |

## 开发者入口

- **SDK** — `aithinker_dev_sdk`，基于 bouffalo_sdk 的中间件与板级封装
- **文档** — [docs.ai-thinker.com](https://docs.ai-thinker.com)
- **示例** — 各开发板仓库的 `examples/` 目录
- **烧录调试** — FlashKey，一键烧录与串口日志采集
