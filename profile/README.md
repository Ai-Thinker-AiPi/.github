## 关于我们 About Us

小安派（AiPi），是**安信可科技 Ai-Thinker** 旗下开源硬件品牌。

我们秉持「让创意安心落地」的品牌承诺，希望打破技术门槛，让每一位爱好者都能更轻松地把想法变成实物，享受从创意到成品的 DIY 智能开发乐趣。
